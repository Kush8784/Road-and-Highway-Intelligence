## What was verified and how
- **Existence, authority, status** — each project's status is tied to a dated source (`status_source`). Tier-1 sources used where reachable: PIB (Sela, Atal Tunnel, Dwarka Delhi section), MMRDA (MTHL, Thane–Borivali), UPEIDA (Ganga), BRO (Atal Tunnel), News On AIR (Vadhavan corridor, Dwarka opening).
- **Contractors & JVs** — package-level only, each with its own source; JV members stored separately with shares where disclosed (Coastal Road HCC 55 % / HDC 45 %).
- **Values** — every reported value kept with type and date. A reference value is flagged only with a reason.

## Known gaps (intentionally not filled)
- Package contractors for Delhi–Mumbai (54 packages), Samruddhi, Bengaluru–Chennai, Delhi–Amritsar–Katra.
- Consultants (DPR, AE/IE/PMC), financiers, O&M operators, technology vendors — none verified.
- Tender IDs, bidders, qualification criteria.
- Surveyed alignments — all geometry is **APPROXIMATE** (town-centre vertices; lines are schematic).
- Publication dates for many sources.
- Stakeholders (project directors etc.).

Each gap is listed in `docs/PROJECT_TRACKER.md › Open verification items`.
